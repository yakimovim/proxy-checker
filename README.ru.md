# Proxy Checker

[English version](./README.md)

Proxy Checker является приложением для проверки доступности прокси-серверов. Существует множество источников информации о различных прокси-серверах. Но это не означает, что все они доступны в том месте, где вы находитесь. Proxy Checker позволяет вам скачивать списки прокси-серверов из различных источников, проверять доступность этих серверов и экспортировать те из них, которые прошли тест.

## Использование UI

Запустите приложение `ProxyChecker`.

Прежде всего, вам необходимо создать экземпляры загрузчиков, проверок и экспортёров. Это можно сделать, выбрав в главном меню пункт `File`, а под ним пункты `Loaders...`, `Checkers...` и `Exporters...`. В каждом случае вы увидите окно со списком соответствующих элементов. С помощью кнопки `Add` вы можете создать новый загрузчик, проверку или экспортёр. В поле `Name` укажите осмысленное имя для вашего элемента. С помощью выпадающего списка ниже выберите нужный вам тип элемента. С помощью кнопки `Settings` вы можете задать настройки для каждого элемента. Кнопка `Delete` позволяет удалить его. Кнопка `Make active` даёт возможность выбрать данный элемент в качестве активного (текущего).

Убедитесь, что вы создали по крайней мере один загрузчик, проверку и экспортёр.

После того, как вы создали загрузчики, вы сможете использовать кнопку `Load` на главном экране. Выпадающий список рядом с ней позволит вам выбрать активный загрузчик.

После загрузки списка прокси-серверов, вы сможете использовать кнопку `Check` для проверки их доступности.

Проверенные прокси могут быть экспортированы с помощью кнопки `Export`.

### Создание файла настроек

Proxy Checker включает в свой состав приложение `ProxyChecker.Cli`, которое может быть использовано в командной строке. Но для этого вам сперва необходимо создать файл настроек. Этот файл содержит описание настроек загрузчика, проверки и экпортёра. Простейший способ создать такой файл - через UI. Откройте приложение `ProxyChecker`. Создайте загрузчик, проверку и экспортёр, настройте их параметры. Затем в главном меню выбетире `File` и `Export settings...`. Выберите путь к создаваемому файлу настроек. Конфигурация загрузчика, проверки и экспортёра будет записана в этот файл.

## Использование CLI

Приложение `ProxyChecker.Cli` может быть использовано для автоматизации получения, проверки и экпорта списка проверенных прокси-серверов.

```ps
ProxyChecker.Cli.exe --settings "c:\Temp\settings.json"
```

Файл `settings.json` должен содержать описание конфигурации загрузчика, проверки и экспортёра. Простейший способ создания этого файла - через UI, как это описано выше.

## Расширение функциональности

Proxy Checker основан на [технологии MEF](https://learn.microsoft.com/en-us/dotnet/standard/mef/). Все загрузчики, проверки и экспортёры представляют собой просто плагины. Ничто не мешает вам создать собственный новый плагин. Вот как это можно сделать.

Создайте новый проект типа `Class Library`. Используйте ту же версию .NET, что и проект [ProxyChecker](./ProxyChecker/ProxyChecker.csproj). Добавьте в ваш проект ссылку на сборку `ProxyChecker.Interfaces`, которую вы можете найти в папке, куда вы установили Proxy Checker. Если вам нужны дополнительные NuGet-пакеты, взгляните на версии уже используемых пакетов в файле [Directory.Packages.props](./Directory.Packages.props). Пожалуйста, используйте те же версии, чтобы избежать проблем с совместимостью.

Если вы хотите создать свой загрузчик, вам необходимо реализовать интерфейс [ILoader](./ProxyChecker.Interfaces/Loaders/ILoader.cs) из сборки `ProxyChecker.Interfaces`. Используйте интерфейс [IChecker](./ProxyChecker.Interfaces/Checkers/IChecker.cs) для создания проверки и интерфейс [IExporter](./ProxyChecker.Interfaces/Exporters/IExporter.cs) для экспортёра. Крайне рекомендуется посмотреть, как аналогичные элементы созданы в проекте Proxy Checker.

Реализуйте фабрику для вашего нового элемента ([ILoaderCreator](./ProxyChecker.Interfaces/Loaders/ILoaderCreator.cs), [ICheckerCreator](./ProxyChecker.Interfaces/Checkers/ICheckerCreator.cs) или [IExporterCreator](./ProxyChecker.Interfaces/Exporters/IExporterCreator.cs)).

Создайте класс `ServicesRegistrator`, который будет регистрировать созданные вами элементы в контейнере зависимостей:

```cs
[Export(typeof(IServicesRegistrator))]
public class ServicesRegistrator : IServicesRegistrator
{
  public void RegisterServices(IServiceCollection services)
  {
    services.AddTransient<ILoaderCreator, LoaderCreator>();
  }
}
```

Когда вы будете удовлетворены вашим кодом, выполните .NET-публикацию в self-contained режиме:

```ps
dotnet publish -o publish --sc -r win-x64
```

Опция `--sc` заставляет публикацию создать результат, не требующий присутствия установленного .NET.

Вам нет необходимости распространять сборки из NuGet пакетов, если они уже являются частью Proxy Checker и могут быть найдены в папке, куда вы установили Proxy Checker.

В этой главной папке перейдите в подкаталог `Plugins`. Если вы создавали загрузчик, перейдите в подпапку `Loaders`, для проверки - в `Checkers` и `Exporters` для экспортёра. Здесь создайте повый подкаталог для вашего плагина. Имя этого подкаталога не важно. Поместите в него результат публикации вашего проекта.
